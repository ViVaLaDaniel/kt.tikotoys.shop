## 2025-03-01 - Optimize React Context Re-Renders
**Learning:** Context provider objects and callback functions need to be memoized using `useMemo` and `useCallback`, especially for global state contexts like `CartContext` and `ProductsContext` in a React app. Otherwise, every state update within the provider creates new reference identities for all context functions, forcing re-renders of all consumer components, even if they only needed specific actions like `addToCart`.
**Action:** When creating Context providers, meticulously wrap the `value` object in `useMemo` and explicitly wrap all exposed functional actions in `useCallback`. Ensure internal state updates rely on functional state updates (e.g., `setItems(prev => ...)`) so callbacks don't have dependency arrays that constantly change.
