## 🚀 Быстрый старт

### Требования:
- Node.js 18+ и npm
- Firebase аккаунт

### Установка:

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd Cards

# 2. Установить зависимости
npm install

# 3. Настроить Firebase
# Создайте файл .env в корне проекта и добавьте в него
# ваши ключи конфигурации Firebase:
# VITE_FIREBASE_API_KEY=...
# VITE_FIREBASE_AUTH_DOMAIN=...
# VITE_FIREBASE_PROJECT_ID=...
# ... и остальные ключи

# (Опционально) Настроить Supabase
# VITE_SUPABASE_URL=...
# VITE_SUPABASE_ANON_KEY=...

# 4. Запустить dev-сервер
npm run dev

# 5. Открыть в браузере
# http://localhost:5173 (или другой порт, указанный в терминале)
```

### Supabase (опционально)

Если указаны переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`,
каталог товаров будет загружаться и обновляться через Supabase вместо localStorage.

Минимальная схема таблицы `products`:

```sql
create table if not exists public.products (
  id bigint generated by default as identity primary key,
  name text not null,
  price numeric not null,
  currency text not null,
  imageUrl text[] not null,
  description text not null,
  rating numeric not null,
  reviewCount integer not null,
  category text
);

alter table public.products enable row level security;

create policy "public read" on public.products
  for select
  using (true);
```

## 🔑 Как войти

### Для покупателей:
1.  Нажмите кнопку "Login" на главной странице.
2.  Войдите, используя ваш Google аккаунт.

### Для администратора:
1.  Войдите с Google аккаунта, email которого: `admin@kt.tikotoys.shop`.
2.  После входа у вас появится доступ к админ-панели через меню пользователя.

## 💡 Функционал

### Контексты

#### 1. AuthContext
**Файл:** `src/context/AuthContext.tsx`

**Ключевые функции:**
- `signInWithGoogle()` - Инициирует процесс входа через Google.
- `logout()` - Выход из системы.
- `user` - Объект текущего пользователя (из Firebase).
- `isAuthenticated` - Статус аутентификации.

**Хранение:** Состояние управляется Firebase SDK в реальном времени.

#### 2. CartContext
**Файл:** `src/context/CartContext.tsx`

**Хранение:** localStorage (`kt-tikotoys-cart`)
