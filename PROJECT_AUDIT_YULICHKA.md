# Промпт для ИИ-ассистента и полная проверка проекта «Юличкины мягкие игрушки»

## 1) Готовый промпт для ИИ (можно вставлять в новый чат)

```
Ты — senior full-stack ревьюер e-commerce проекта на React + TypeScript.
Контекст: проект — интернет-магазин мягких игрушек «Юличкины игрушки».

Твоя задача: провести полный аудит проекта и выдать план улучшений по приоритетам.

Проверь:
1. Архитектуру и структуру папок.
2. Типизацию TypeScript (ошибки, несовместимости типов, nullable значения).
3. Аутентификацию и управление сессией (безопасность, UX, edge cases).
4. Корзину и checkout (валидации, устойчивость, корректность totals).
5. Заказы и профиль пользователя (согласованность id и дат, хранение в localStorage).
6. SEO и мета-теги для страниц магазина.
7. Производительность (bundle size, lazy loading, split chunks).
8. Доступность (a11y), мобильную адаптивность и UX.
9. Ошибки сборки/линта/тестов и CI-ready состояние.
10. Конфигурацию и секреты (env, публичные ключи, безопасные практики).

Формат ответа:
- Краткий итог (1 абзац).
- Таблица найденных проблем: [Severity | Где | Что не так | Риск | Как исправить].
- Отдельно: quick wins (до 1 часа), medium задачи (1–2 дня), backlog.
- Отдельно: checklist для релиза v1.
- Если данные неочевидны — явно помечай предположения.
```

## 2) Что проверено в текущем проекте

- Линт: `npm run lint`
- Тесты: `npm test -- --runInBand`
- Сборка production: `npm run build`
- TypeScript strict check: `npx tsc --noEmit`
- Security audit: `npm audit --audit-level=high`

## 3) Результаты и исправления

### Исправлено
1. Добавлена отсутствующая `register`-функция в `AuthContext` с Firebase email/password регистрацией.
2. В `AppUser` добавлено поле `createdAt`, чтобы профиль корректно отображал дату регистрации.
3. Унифицирован идентификатор пользователя в заказах: переход с `number` на `string` (`uid` из Firebase).
4. Исправлен checkout и страница заказов: теперь используют `user.uid`.
5. Исправлена типизация Vite plugins (`PluginOption[]`) для корректной TypeScript-проверки.

### Проверка после исправлений
- Линт проходит.
- TypeScript-проверка проходит без ошибок.
- Production build проходит.
- Тестов в проекте пока нет (Jest завершает с `No tests found`).
- `npm audit` в окружении блокируется ответом registry `403 Forbidden` (ограничение среды).
